# Portfolio Project starter

A plain Quarto website skeleton for the OMIS 681 Portfolio Project. Unstyled on purpose: make it yours.

## Use

New to R, Git or Netlify? Read SETUP_GUIDE.md first: it walks through every install and account, step by step.

1. Press "Use this template" on GitHub to create your own copy.
2. Clone it and double-click portfolio-project.Rproj so RStudio opens it as a Project (this keeps your working directory right automatically).
3. Put your CSV in a `data/` folder (it stays out of git; see .gitignore).
4. Edit the five pages; every TODO comment tells you what goes where.
5. Render the site (Build pane, Render Website), commit, push.
6. Connect the repository to Netlify (see the Pre-Flight instructions); every push republishes your site.

## Rules that keep you safe

- The data file never gets committed and never gets linked from the site.
- Numbers in your text come from executed code, not from memory.
- Push every working session, not just at deadlines.
